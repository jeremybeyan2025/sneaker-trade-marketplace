# Product Requirements Document

## Working Name

SoleVault

## Positioning

The authenticated sneaker marketplace built around **trades**, not just cash sales.

## Audience

- Sneaker collectors
- Resellers
- Local boutique sellers
- Streetwear buyers
- Trade-first collectors who hate Facebook group scams

## MVP User Stories

### Buyer

- Browse listings by brand/model/SKU/size/condition
- See ask price, last sale, seller reputation, and authentication status
- Buy with escrow
- Track seller shipment -> authentication -> delivery

### Seller

- Create listing by SKU
- Upload required photos
- Receive prepaid label after sale
- Get paid after authentication pass

### Trader

- Add sneakers to digital closet
- Make trade offers with optional cash difference
- Both parties ship to authentication
- Trade completes only if both items pass

### Admin/Auth Team

- Review uploaded photos
- Review physical authentication queue
- Pass/fail item
- Trigger refund, payout, or trade unwind

## Differentiator

StockX focuses on bid/ask. GOAT focuses on curated sellers and condition. eBay is broad marketplace plus authentication. SoleVault's wedge is authenticated **trade escrow** with social drop rooms.
