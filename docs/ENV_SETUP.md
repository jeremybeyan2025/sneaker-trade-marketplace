# Environment Setup

Create a local environment file before connecting live services.

Required values:

- Public Supabase project URL
- Public Supabase browser key
- Server-only Supabase service key
- Stripe secret key
- Stripe webhook signing value
- Public app URL

Recommended local app URL:

```text
http://localhost:3000
```

Never commit a real local environment file or live payment credentials to GitHub.
